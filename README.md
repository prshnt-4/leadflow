# LeadFlow

A modern Lead Management Platform built with Next.js, TypeScript, MongoDB, and Auth.js.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- MongoDB Atlas
- Mongoose
- Auth.js
- Framer Motion

## Features

- Modern SaaS Landing Page
- Lead Capture Form
- Secure Authentication
- Dashboard
- Lead Management
- Search & Filter
- Responsive Design

## Getting Started

```bash
npm install
npm run dev
```

Visit:

http://localhost:3000
